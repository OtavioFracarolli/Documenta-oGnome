1. O que é o Terminal e para que serve?

O terminal (como o GNOME Terminal ou Console) é uma interface de linha de comando (CLI) que permite controlar o sistema operacional diretamente por texto. Ele oferece maior rapidez, automação e acesso profundo ao sistema que a interface gráfica (GUI) não permite.

2. Atalhos Essenciais no GNOME Terminal

  • Ctrl + Alt + T — Abre a janela do terminal no ambiente GNOME.
  • Ctrl + Shift + T — Abre uma nova aba na mesma janela.
  • Ctrl + Shift + W — Fecha a aba atual.
  • Ctrl + Shift + C — Copia o texto selecionado no terminal.
  • Ctrl + Shift + V — Cola o conteúdo copiado no terminal.
  • Ctrl + L — Limpa a tela (equivalente ao comando clear).
  • Ctrl + C — Interrompe/cancela a execução do comando atual.
  • Ctrl + Z — Pausa a execução do processo em primeiro plano.
  • Ctrl + A — Move o cursor para o início da linha.
  • Ctrl + E — Move o cursor para o final da linha.
  • Ctrl + U — Apaga tudo do cursor até o início da linha.
  • Ctrl + K — Apaga tudo do cursor até o final da linha.
  • Tab — Autocompleta comandos, nomes de pastas e caminhos de arquivos.
  • Seta ↑ / Seta ↓ — Navega pelo histórico de comandos executados.

3. Navegação e Caminhos

  1. pwd (Print Working Directory) — Exibe o caminho completo do diretório onde você está.
    Exemplo: pwd
  2. cd (Change Directory) — Navega entre as pastas do sistema.
    Exemplos:
    • cd Documentos — Entra na pasta Documentos.
    • cd .. — Sobe um nível (volta para a pasta anterior).
    • cd ~ ou apenas cd — Vai direto para a pasta pessoal do usuário (/home/usuario).
    • cd - — Volta para o diretório em que você estava antes do último comando cd.
  3. ls (List) — Lista os arquivos e pastas no diretório atual.
    Opções úteis:
    • ls -l — Mostra detalhes (permissões, tamanho, data de modificação).
    • ls -a — Mostra todos os arquivos, incluindo os ocultos (que começam com ponto, ex: .bashrc).
    • ls -lh — Exibe os tamanhos de arquivos em formato legível para humanos (KB, MB, GB).
Símbolos de Caminho:
. (diretório atual) | .. (diretório pai/anterior) | ~ (pasta Home) | / (raiz do sistema).

4. Gerenciamento de Arquivos e Pastas

  1. mkdir (Make Directory) — Cria uma nova pasta.
    Ex: mkdir Projetos ou mkdir -p Pasta1/Pasta2 (cria subpastas encadeadas).
  2. touch — Cria um arquivo vazio ou atualiza a data de modificação de um existente.
    Ex: touch notas.txt
  3. cp (Copy) — Copia arquivos ou diretórios.
    Ex: cp relatorio.txt copia_relatorio.txt
    Para pastas use o parâmetro recursivo -r: cp -r MinhaPasta CopiaPasta
  4. mv (Move) — Movel ou renomeia arquivos e pastas.
    Ex: mv antigo.txt novo.txt (renomeia)
    Ex: mv foto.jpg ~/Imagens/ (move para a pasta Imagens)
  5. rm (Remove) — Exclui arquivos permanentemente.
    Ex: rm arquivo.txt
    Para apagar uma pasta e todo o seu conteúdo: rm -r minha_pasta
  6. rmdir — Remove pastas vazias. Ex: rmdir pasta_vazia
  7. cat / less — Exibe o conteúdo de um arquivo de texto no terminal.
    Ex: cat texto.txt ou less texto.txt (ideal para arquivos longos).
  8. nano — Editor de texto leve e simples direto no terminal.
    Ex: nano documento.txt (use Ctrl + O para salvar e Ctrl + X para sair).

5. Permissões de Arquivos

No Linux, cada arquivo tem permissões para **Dono (u)**, **Grupo (g)** e **Outros (o)**.

  • chmod — Altera as permissões de acesso.
    Exemplo para tornar um script executável: chmod +x script.sh
    Exemplo numérico (leitura/escrita/execução): chmod 755 meu_programa
  • chown — Altera o proprietário/grupo do arquivo.
    Exemplo: sudo chown usuario:grupo arquivo.txt

6. Gerenciamento de Pacotes e Programas

A) APT (Padrão no Ubuntu, Debian, Pop!_OS e Mint)

  1. sudo apt update — Atualiza o índice dos repositórios.
  2. sudo apt upgrade — Atualiza todos os programas instalados para as versões mais recentes.
  3. sudo apt install nome-do-pacote — Instala um novo programa (Ex: sudo apt install vlc).
  4. sudo apt remove nome-do-pacote — Remove um programa mantendo as configurações.
  5. sudo apt autoremove — Remove dependências e arquivos que não são mais utilizados.

B) Flatpak (O ecossistema oficial de apps do GNOME)

  1. flatpak update — Atualiza os aplicativos em Flatpak.
  2. flatpak install flathub com.spotify.Client — Instala um aplicativo do Flathub.
  3. flatpak list — Lista todos os aplicativos Flatpak instalados.

7. Execução e Controle do Sistema

  • xdg-open arquivo_ou_link — Abre qualquer arquivo ou URL no aplicativo padrão configurado no GNOME. Ex: xdg-open documento.pdf
  • python3 script.py — Executa scripts da linguagem Python.
  • ./script.sh — Executa um script de Shell (necessita de permissão +x).
  • ps aux — Lista todos os processos ativos no sistema.
  • kill PID — Encerra um processo através do seu ID (PID).
  • killall nome_do_programa — Encerra todas as instâncias de um programa. Ex: killall firefox

8. Utilitários e Informações do Sistema

  1. htop — Monitor interativo de uso de CPU, RAM e gerenciador de processos.
    Instalação: sudo apt install htop
  2. tree — Exibe o mapa visual dos diretórios em estrutura de árvore.
    Instalação: sudo apt install tree
  3. neofetch ou fastfetch — Exibe dados do sistema e o logo da distribuição/desktop GNOME.
    Instalação: sudo apt install neofetch
  4. df -h — Mostra o espaço livre e ocupado nas partições do disco rígido/SSD.
  5. free -h — Exibe o consumo de memória RAM do sistema em tempo real.

9. Comandos Divertidos

  • cmatrix — Efeito visual de código caindo estilo o filme The Matrix. (sudo apt install cmatrix)
  • cowsay "mensagem" — Exibe uma vaca ASCII dizendo a sua frase. (sudo apt install cowsay)
  • lolcat — Adiciona coloração em gradiente de arco-íris a qualquer saída do terminal. Ex: neofetch | lolcat
  • sl — Uma animação de um trem cruzando o terminal quando você digita sl em vez de ls. (sudo apt install sl)

10. Boas Práticas e Dicas de Segurança

ATENÇÃO:
  • Use a palavra sudo (Super User DO) apenas quando necessário para tarefas administrativas. Executar tudo como root pode comprometer a estabilidade do sistema.
  • NUNCA execute o comando rm -rf / ou variações sem entender exatamente o que está fazendo, pois ele excluirá todo o conteúdo do seu disco sem pedir confirmação.
  • Os arquivos deletados no terminal com o comando rm NÃO passam pela Lixeira do GNOME e são apagados definitivamente.
